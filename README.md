# 📊 店舗予約データ集計アプリ

店舗予約データをCSVファイルからアップロードして、期間・店舗別に集計するWebアプリケーションです。

## 🌟 機能

### 主な機能
- **CSVファイルアップロード**: ドラッグ&ドロップまたはボタンでCSVファイルを簡単アップロード
- **データプレビュー**: アップロード後、データの最初の10行を確認
- **柔軟な集計条件**:
  - 📅 期間選択（カレンダーUIで開始日・終了日を選択）
  - 🏪 店舗選択（複数選択可、全選択ボタン付き）
  - 📊 集計単位（月次・日別から選択）
- **集計結果表示**: テーブル形式で見やすく表示
- **CSVダウンロード**: 集計結果をCSVファイルでダウンロード可能

### データ処理
- **重複除外**: Summary列の重複データを除外してカウント
- **利用時間計算**: 開始日時と終了日時から利用時間を自動計算（時間単位、小数点第1位）

## 📋 CSVファイル形式

以下の列を含むCSVファイルをアップロードしてください：

| 列名 | 説明 | 形式例 |
|------|------|--------|
| ID | 予約ID | 数値 |
| Type | タイプ | 文字列 |
| Resource Calendar Interface ID | リソースカレンダーインターフェースID | 文字列 |
| Reservation Content ID | 予約コンテンツID | 文字列 |
| 開始日時 | 予約開始日時 | `2025-11-16, 23:15` |
| 終了日時 | 予約終了日時 | `2025-11-16, 23:15` |
| Summary | 予約サマリー | 文字列 |
| 店名 | 店舗名 | 文字列 |
| リソース名 | リソース名 | 文字列 |
| タイプ | タイプ | 文字列 |
| カテゴリ | カテゴリ | 文字列 |
| 人数制限 | 人数制限 | 数値 |

### 日時形式の注意点
開始日時・終了日時は `YYYY-MM-DD, HH:MM` の形式で記載してください。

例: `2025-11-16, 23:15`

## 🚀 Streamlit Cloudへのデプロイ手順

### 前提条件
- GitHubアカウント
- Streamlit Cloudアカウント（GitHubアカウントで無料登録可能）

### デプロイ手順

#### 1. GitHubリポジトリの準備
このリポジトリをGitHubにプッシュします。

```bash
git add .
git commit -m "Initial commit: 店舗予約データ集計アプリ"
git push origin main
```

#### 2. Streamlit Cloudにログイン
1. [Streamlit Cloud](https://streamlit.io/cloud) にアクセス
2. GitHubアカウントでサインイン

#### 3. アプリをデプロイ
1. Streamlit Cloudのダッシュボードで「New app」をクリック
2. 以下の情報を入力:
   - **Repository**: このリポジトリを選択
   - **Branch**: `main` (またはデフォルトブランチ)
   - **Main file path**: `app.py`
3. 「Deploy!」をクリック

#### 4. デプロイ完了
数分後、アプリが自動的にデプロイされ、URLが発行されます。
このURLを共有すれば、誰でもブラウザからアクセスできます！

### デプロイ後の使い方
- 発行されたURLにアクセスするだけで使用可能
- Pythonのインストール不要
- ブラウザがあればどこからでもアクセス可能

## 💻 ローカルでの実行方法

Streamlit Cloudではなく、ローカル環境で実行する場合：

### 1. リポジトリをクローン
```bash
git clone <repository-url>
cd iio-kadouritu
```

### 2. 依存パッケージをインストール
```bash
pip install -r requirements.txt
```

### 3. アプリを起動
```bash
streamlit run app.py
```

### 4. ブラウザでアクセス
自動的にブラウザが開きます。開かない場合は以下にアクセス:
```
http://localhost:8501
```

## 📊 集計結果の出力項目

集計結果には以下の項目が含まれます：

| 項目 | 説明 | 形式例 |
|------|------|--------|
| 期間 | 集計期間 | 月次: `2025-11`, 日別: `2025-11-16` |
| 店名 | 店舗名 | 文字列 |
| 利用件数合計 | Summary重複除外後の件数 | 数値 |
| 合計時間 | 利用時間の合計（時間） | `12.5` |
