# 📊 店舗予約データ集計アプリ

CSVファイルをアップロードするだけで、店舗予約データを簡単に集計できるアプリです。

## 🎯 このアプリで何ができる？

- 📅 期間を指定して集計（月次・日別）
- 🏪 店舗を選んで集計
- 👥 人数制限で絞り込み（例：10人〜30人の会議室のみ）
- ⏰ 時間帯を指定（例：10時〜19時の稼働率）
- 📊 稼働率の自動計算
- 📥 集計結果をCSVでダウンロード

---

## 🚀 使い方（3ステップで起動！）

### ステップ1: Pythonをインストール

初回のみ必要です。既にインストール済みの方はスキップしてください。

**Windows / Mac 共通**
1. [Python公式サイト](https://www.python.org/downloads/)にアクセス
2. 「Download Python」ボタンをクリックしてダウンロード
3. ダウンロードしたファイルをダブルクリックしてインストール
   - ⚠️ **Windows の方**: 「Add Python to PATH」に必ずチェックを入れてください

### ステップ2: アプリをダウンロード

1. このGitHubページの上部にある緑色の **「Code」** ボタンをクリック
2. **「Download ZIP」** を選択
3. ダウンロードしたZIPファイルをダブルクリックで解凍
4. 解凍したフォルダを好きな場所に移動（デスクトップや書類フォルダなど）

### ステップ3: アプリを起動（ダブルクリックだけ！）

解凍したフォルダの中にある起動ファイルをダブルクリックするだけです：

- **Windows の方**: `start.bat` をダブルクリック
- **Mac の方**: `start.command` を**右クリック → 「開く」**
  - ⚠️ 初回は「マルウェア」警告が出ますが、これは正常です
  - 右クリック → 「開く」で実行してください（詳しくは下の「よくある質問」参照）
  - 2回目以降は普通にダブルクリックでOK

自動的にブラウザが開いてアプリが起動します！

> 💡 初回起動時は必要なファイルを自動でインストールするため、少し時間がかかります（1〜2分程度）

### アプリを終了するには

開いたターミナル/コマンドプロンプトのウィンドウを閉じるだけです。

## ⚠️ よくある質問

<details>
<summary><strong>【Mac】「マルウェアが含まれている可能性」と警告が出る</strong></summary>

これはMacのセキュリティ機能（Gatekeeper）による正常な警告です。
ダウンロードしたスクリプトがAppleの署名を持っていないため表示されます。

**解決方法（簡単）**:
1. `start.command` を **右クリック**（または Control + クリック）
2. メニューから **「開く」** を選択
3. 「開いてもよろしいですか？」と表示されるので **「開く」** をクリック
4. 次回以降は普通にダブルクリックで起動できます

**別の方法**:
1. システム環境設定を開く
2. 「セキュリティとプライバシー」をクリック
3. 「一般」タブで「このまま開く」ボタンが表示されているのでクリック

</details>

<details>
<summary><strong>Pythonって何？インストールしたことない...</strong></summary>

Pythonはプログラミング言語の一つです。このアプリを動かすのに必要です。
上記の「ステップ1」の手順でインストールできます。無料です。

</details>

<details>
<summary><strong>「Add Python to PATH」って何？</strong></summary>

Windowsでのインストール時にチェックする項目です。
これにチェックを入れないとアプリが起動しません。
もし忘れた場合は、Pythonを再インストールしてください。

</details>

<details>
<summary><strong>start.bat や start.command をダブルクリックしても何も起こらない</strong></summary>

以下を確認してください：
1. Pythonがインストールされているか
2. (Windows) Pythonインストール時に「Add Python to PATH」にチェックを入れたか
3. インターネットに接続されているか（初回のみ必要）

それでも起動しない場合は、Pythonを再インストールしてみてください。

</details>

<details>
<summary><strong>2回目以降も毎回時間がかかる？</strong></summary>

いいえ、2回目以降はすぐに起動します。
初回のみ必要なファイルをインストールするため時間がかかります。

</details>

<details>
<summary><strong>エラーが出て起動できない</strong></summary>

以下を試してください：
1. Pythonを再インストール（「Add Python to PATH」を忘れずに）
2. ウイルス対策ソフトを一時的に無効にしてみる
3. 管理者として実行する（ファイルを右クリック → 「管理者として実行」）

</details>

## 📚 付録: 技術情報

<details>
<summary><strong>CSVファイルの形式</strong></summary>

以下の列を含むCSVファイルをアップロードしてください：

- ID
- Type
- Resource Calendar Interface ID
- Reservation Content ID
- **開始日時**（形式: `2025-11-16, 23:15`）
- **終了日時**（形式: `2025-11-16, 23:15`）
- **Summary**
- **店名**
- リソース名
- タイプ
- カテゴリ
- **人数制限**

太字は必須項目です。

</details>

<details>
<summary><strong>稼働率の計算方法</strong></summary>

稼働率は以下の計算式で算出されます：

```
稼働率（%） = 実際の利用時間 ÷ (リソース数 × 営業時間 × 日数) × 100
```

**計算例**:
- リソース数: 3個
- 営業時間: 10時〜19時（9時間）
- 期間: 30日間
- 実際の利用時間: 270時間

```
分母 = 3 × 9 × 30 = 810時間
稼働率 = 270 ÷ 810 × 100 = 33.3%
```

</details>
