# 📊 店舗予約データ集計アプリ

店舗予約データをCSVファイルからアップロードして、期間・店舗別に集計するWebアプリケーションです。

## 🌟 機能

### 主な機能
- **CSVファイルアップロード**: ドラッグ&ドロップまたはボタンでCSVファイルを簡単アップロード
- **データプレビュー**: アップロード後、データの最初の10行を確認
- **柔軟な集計条件**:
  - 📅 期間選択（カレンダーUIで開始日・終了日を選択）
  - 🏪 店舗選択（複数選択可、全選択ボタン付き）
  - 📊 集計単位（月次・日別から選択）
  - 👥 人数制限フィルタリング（オプション：人数制限で絞り込み）
  - ⏰ 時間帯指定（オプション：営業時間帯を指定して集計）
- **稼働率計算**: 店舗別のリソース数を入力して稼働率を自動算出（オプション）
- **集計結果表示**: テーブル形式で見やすく表示
- **CSVダウンロード**: 集計結果をCSVファイルでダウンロード可能

### データ処理
- **重複除外**: Summary列の重複データを除外してカウント
- **利用時間計算**: 開始日時と終了日時から利用時間を自動計算（時間単位、小数点第1位）
- **人数制限フィルタリング**: 指定した人数範囲のデータのみを集計対象にします
- **時間帯フィルタリング**: 指定した時間帯と予約の重複部分のみを集計対象にします
- **稼働率算出**: リソース数と営業時間から稼働率を自動計算

## 📋 CSVファイル形式

以下の列を含むCSVファイルをアップロードしてください：

| 列名 | 説明 | 形式例 |
|------|------|--------|
| ID | 予約ID | 数値 |
| Type | タイプ | 文字列 |
| Resource Calendar Interface ID | リソースカレンダーインターフェースID | 文字列 |
| Reservation Content ID | 予約コンテンツID | 文字列 |
| 開始日時 | 予約開始日時 | `2025-11-16, 23:15` |
| 終了日時 | 予約終了日時 | `2025-11-16, 23:15` |
| Summary | 予約サマリー | 文字列 |
| 店名 | 店舗名 | 文字列 |
| リソース名 | リソース名 | 文字列 |
| タイプ | タイプ | 文字列 |
| カテゴリ | カテゴリ | 文字列 |
| 人数制限 | 人数制限 | 数値 |

### 日時形式の注意点
開始日時・終了日時は `YYYY-MM-DD, HH:MM` の形式で記載してください。

例: `2025-11-16, 23:15`

## 🚀 Mac でのローカル実行方法（推奨）

非エンジニアでも簡単に実行できるように手順を詳しく説明します。

### 前提条件

- Mac OS（すべてのMacユーザー対応）
- インターネット接続

### ステップ1: Pythonのインストール確認

1. **ターミナル**を開く
   - Spotlight検索（Command + Space）で「ターミナル」と入力
   - またはアプリケーション → ユーティリティ → ターミナル

2. 以下のコマンドを入力してEnter:
   ```bash
   python3 --version
   ```

3. バージョンが表示されればOK（例: `Python 3.9.6`）
   - 表示されない場合は[Python公式サイト](https://www.python.org/downloads/)からインストール

### ステップ2: アプリをダウンロード

**方法A: ZIPファイルでダウンロード（簡単）**
1. GitHubのこのリポジトリページにアクセス
2. 緑色の「Code」ボタンをクリック
3. 「Download ZIP」を選択
4. ダウンロードしたZIPファイルをダブルクリックで解凍
5. 解凍したフォルダを「書類」フォルダなど分かりやすい場所に移動

**方法B: Git でクローン（推奨）**
```bash
cd ~/Documents
git clone <repository-url>
cd iio-kadouritu
```

### ステップ3: アプリを起動

1. ターミナルでアプリのフォルダに移動:
   ```bash
   cd ~/Documents/iio-kadouritu
   ```
   ※ フォルダの場所が違う場合は適宜変更してください

2. **初回のみ**: 依存パッケージをインストール:
   ```bash
   pip3 install -r requirements.txt
   ```
   ※ これは最初の1回だけ実行すればOKです

3. アプリを起動:
   ```bash
   streamlit run app.py
   ```

4. 自動的にブラウザが開いてアプリが表示されます
   - 開かない場合は、ターミナルに表示される `http://localhost:8501` をブラウザで開く

### ステップ4: アプリを終了

- ターミナルで `Control + C` を押す
- ターミナルを閉じる

### 🎯 次回以降の起動方法

2回目以降は簡単です：

1. ターミナルを開く
2. 以下のコマンドを実行:
   ```bash
   cd ~/Documents/iio-kadouritu
   streamlit run app.py
   ```
3. ブラウザでアプリが開きます

### 💡 さらに簡単にする方法

**ワンクリック起動スクリプト**を使うと、毎回コマンドを入力する必要がなくなります。

1. プロジェクトフォルダ内の `start.command` ファイルをダブルクリック
2. 自動的にアプリが起動します

詳しくは `start.command` ファイルをご覧ください。

### ⚠️ トラブルシューティング

**「command not found」エラーが出る場合**
```bash

# streamlit が見つからない場合
python3 -m streamlit run app.py
```

**ポートが使用中の場合**
```bash

```

**古いバージョンを削除したい場合**
```bash

```

## 📊 集計結果の出力項目

集計結果には以下の項目が含まれます：

| 項目 | 説明 | 形式例 |
|------|------|--------|
| 期間 | 集計期間 | 月次: `2025-11`, 日別: `2025-11-16` |
| 店名 | 店舗名 | 文字列 |
| 利用件数合計 | Summary重複除外後の件数 | 数値 |
| 合計時間（時間） | 利用時間の合計（**時間単位**） | `12.5` |
| 稼働率（%） | リソース稼働率（オプション） | `25.3` |

### 稼働率の計算方法

稼働率は以下の計算式で算出されます：

```
稼働率（%） = 実際の利用時間 ÷ (リソース数 × 営業時間 × 期間の日数) × 100
```

#### 計算例

**例1: 時間帯指定なしの場合（24時間営業）**
- 店舗: 東京店
- リソース数: 3個
- 集計単位: 月次（30日間）
- 実際の利用時間: 540時間

```
分母 = 3 × 24 × 30 = 2,160時間
稼働率 = 540 ÷ 2,160 × 100 = 25.0%
```

**例2: 時間帯指定ありの場合（10時〜19時）**
- 店舗: 大阪店
- リソース数: 2個
- 営業時間: 10時〜19時（9時間）
- 集計単位: 月次（30日間）
- 実際の利用時間: 270時間

```
分母 = 2 × 9 × 30 = 540時間
稼働率 = 270 ÷ 540 × 100 = 50.0%
```

**例3: 日別集計の場合**
- 店舗: 名古屋店
- リソース数: 5個
- 営業時間: 10時〜19時（9時間）
- 集計単位: 日別（1日）
- 実際の利用時間: 18時間

```
分母 = 5 × 9 × 1 = 45時間
稼働率 = 18 ÷ 45 × 100 = 40.0%
```
